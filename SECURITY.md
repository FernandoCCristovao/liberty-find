# Segurança

## Como relatar uma vulnerabilidade

Use o relato privado do GitHub: aba **Security**, botão **Report a vulnerability**. Não abra issue
pública para falha de segurança.

Inclua o que for possível: o que você encontrou, como reproduzir e o impacto que imagina. Não envie
dado pessoal de terceiros nem credenciais no relato.

## O que está no escopo

- Código deste repositório e a infraestrutura descrita nele.
- Exposição de dado pessoal, credencial ou descrição de vaga que deveria ser privada.
- Formas de fazer o sistema executar instruções vindas do texto de uma vaga.

## Resposta

O relato é confirmado assim que for lido, e a correção é priorizada pelo impacto. Quem relatar de
boa-fé recebe crédito na correção, se quiser.
